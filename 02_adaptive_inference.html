Every word pays for every visual token

  • Dense attention: each generated token attends to all visual tokens, even when a word needs one region.
  • High-res images and long videos: visual KV attention becomes the main decoding cost.
  • Compression and eviction decide what to keep during prefill, before knowing what each word needs.
Each grid cell is one visual token

Gaze Attention: route each word to the regions it needs

  • Regions: visual keys grouped by space and time (6×6×1 tokens); a descriptor is the mean key.
  • Routing: at every decoding step the query scores all descriptors and attends only to its Top-K regions.
  • Context tokens: 4 learnable tokens per image or frame keep the global scene visible.
  • Training: progressive Top-K, dense → sparse. Learned from next-token prediction only, with no gaze labels.
  • The full KV cache stays; a region skipped now can be chosen later.
