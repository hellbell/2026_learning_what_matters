Bottleneck shifts: compute → memory

Pre-training
Post-training(SFT, RL)
Inference(Reasoning, Agents)
Paid once per
generation
Scaling RL (×10, ×100)
~⅔ of all AI compute
(~⅓ in 2023)
  • Post-training is not cheap anymore
    • OpenAI o1 → o3: RL compute ×10
    • Composer 1.5: post-training compute exceeded pre-training
  • Reasoning models cost more with long contexts
    • Output tokens per question grow ~5×/year for reasoning models (~2.2×/year otherwise)
    • Every token adds to the KV cache, so memory becomes the bottleneck
